🎮 **Step-by-Step Guide to Playing Multiplayer (Escape From Playtime Beta)**

For multiplayer to work, both the **HOST** (the person creating the match) and the **GUESTS** (the ones joining) must complete the preliminary steps.

---

### 🛠️ Preliminary Steps (Required for Everyone)

#### 1. Install the Mod Files

1. Drag the "EscapeFromPlaytime" folder and the "SetHostIP.ini" file into the game's main folder (the one that contains EscapeFromPlaytime.exe)

#### 2. Set Up the Virtual Network with Radmin VPN

1. Download and install the free program **Radmin VPN**. (https://www.radmin-vpn.com/es/)
2. Open the program and click the **Power** button (the large power icon) to activate your virtual IP.

---

### 🖥️ If You Are the HOST (Creating the Match)

1. **Create the network in the VPN:**
* In the Radmin VPN window, click the **Create Network** button.
* Set a **Network Name** and a **Password**.
* Send that Name and Password to your friends (the guests).


2. **Copy your IP:**
* At the top of Radmin VPN, you will see large numbers (your virtual IP, e.g., `26.100.XX.XX`). Right-click those numbers and select **Copy IP address**. Keep it handy, as you will need to give it to your guests.


3. **Start the Server in Game:**
* Launch the game normally.
* Once in the main menu, press the **F1** key.
* The game will automatically load the map in multiplayer mode. Wait until you spawn on the map.



---

### 🕹️ If You Are a GUEST (Joining the Match)

1. **Join the VPN network:**
* In the Radmin VPN window, click the **Join Network** button.
* Go to the **Private network** tab, enter the Name and Password provided by the HOST, and click **Join**.


2. **Get the HOST's IP ready:**
* Ask the HOST for their Radmin VPN IP (the numbers they copied in the step above).


3. **Connect to the match in-game:**
* Open the "SetHostIP.ini" file you dragged earlier into the game's main folder and put the IP provided by the HOST after HostIP=Here you put the IP.
* Launch the game and stay on the main menu.
* Press the **F2** key and the game will start loading you directly into your friend's match.
